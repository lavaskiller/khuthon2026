## 0. 문서 개요

### 0.1 목적

베일 MVP 개발에 필요한 기능 단위 동작 명세를 정의한다. 각 기능은 입력, 처리, 출력, 예외 처리, 화면 동작을 포함한다.

### 0.2 표기

- **F-XX-NN**: 기능 ID (도메인-순번)
- **필수**: MVP 포함 / **선택**: 차기 버전
- 도메인: AC(계정), CT(컨텐츠), RV(심사), EX(탐색), IV(시사회), DS(대시보드), NT(알림)

## 1. 계정 (AC)

### F-AC-01 회원가입 (필수)

**입력**

- 이메일, 비밀번호, 비밀번호 확인
- 권한 선택: 소비자 / 창작자
    - 관리자는 가입 화면에 노출되지 않음. 시스템 관리자가 직접 권한 부여
- 약관 동의 체크박스 (서비스 이용약관, 개인정보 처리방침)

**처리**

- 이메일 형식 검증 (정규식)
- 비밀번호 정책 검증 (8자 이상, 영문 + 숫자 조합)
- 비밀번호 일치 여부 확인
- 이메일 중복 체크
- 비밀번호 해싱 (bcrypt 등) 후 저장
- 권한 정보 저장
- 가입 시점 타임스탬프 기록

**출력**

- 소비자 가입 성공 → F-AC-03(취향 온보딩) 화면으로 이동
- 창작자 가입 성공 → 창작자 대시보드로 이동
- 가입 실패 → 사유 메시지 인라인 표시

**예외**

- 이메일 중복: "이미 사용 중인 이메일입니다"
- 비밀번호 정책 위반: 구체적 사유 표시 (예: "비밀번호는 8자 이상이어야 합니다")
- 약관 미동의: "약관에 동의해야 가입할 수 있습니다"

---

### F-AC-02 로그인 (필수)

**입력**: 이메일, 비밀번호

**처리**

- 이메일 존재 여부 확인
- 비밀번호 해시 비교
- 세션/토큰 발급 (만료 정책: 액세스 토큰 1시간, 리프레시 토큰 30일)
- 권한 정보 응답에 포함

**출력**

- 성공 시 → 권한별 메인 화면으로 이동
    - 소비자: 온보딩 미완료면 F-AC-03, 완료면 F-EX-01 또는 F-EX-02
    - 창작자: 창작자 대시보드
    - 관리자: 미심사 컨텐츠 리스트
- 실패 시 → "이메일 또는 비밀번호가 올바르지 않습니다" (이메일 존재 여부는 노출하지 않음)

**예외**

- 5회 연속 실패 시 5분간 로그인 제한
- 토큰 만료 시 자동 로그아웃 + 로그인 화면 이동

---

### F-AC-03 소비자 취향 온보딩 (필수)

**목적**
소비자의 기본 인구통계 정보와 취향 데이터를 수집하여, 창작자 통계 대시보드의 도달 분석과 플랫폼 내부의 콘텐츠 매칭/다양성 알고리즘에 활용한다. 베일의 블라인드 원칙상 이 데이터는 소비자 화면에 노출되지 않으며, 오직 백엔드와 창작자 통계에서만 활용된다.

**입력 항목**

| 항목 | 타입 | 필수 여부 | 비고 |
| --- | --- | --- | --- |
| 생년월일 | 단일 선택 | **필수** | YYYY-mm-dd |
| 성별 | 단일 선택 | **필수** | 남성 / 여성 / 밝히지 않음 |
| 지역 | 단일 선택 | 선택 | 광역시·도 단위 (서울, 경기, 부산 등 17개 행정구역) |
| 선호 장르 | 다중 선택 | **필수, 최소 1개** | 표준 13개 분류 |
| 콘텐츠 종류별 가중치 | 다중 선택 | 선택 | 4개 옵션 |

**선호 장르 (표준 13개)**
액션 / 드라마 / 코미디 / 로맨스 / 스릴러 / 호러 / SF / 판타지 / 미스터리 / 다큐멘터리 / 애니메이션 / 가족 / 음악

다중 선택 가능, 최소 1개 필수. 최대 선택 개수 제한 없음.

**콘텐츠 종류별 가중치 (선택)**
다중 선택 가능. 주로 어떤 종류를 즐겨 보는지 표시:

- 영화
- 드라마
- 책
- 공연

선택한 항목은 탐색 시 노출 우선순위에 약하게 반영된다. 단, 사용자가 콘텐츠 종류 필터를 직접 설정하면 그 설정이 우선한다.

**처리 로직**

- 연령대 미선택 시 인라인 오류
- 선호 장르 0개 선택 시 인라인 오류
- 선택 항목 미입력은 허용
- User 엔티티에 항목별 저장
- 온보딩 완료 플래그(`onboarding_completed`) true 처리
- 저장 시점 타임스탬프(`onboarding_completed_at`) 기록

**완료 후 이동**

- 콘텐츠 종류 필터 화면(F-EX-01)으로 이동

**스킵 정책**

- 연령대, 성별, 선호 장르: 스킵 불가
- 지역, 종류 가중치: 스킵 가능
- 온보딩 화면 자체를 통째로 스킵하는 옵션은 제공하지 않음

**데이터 수정**

- 언제든 설정 화면에서 모든 온보딩 항목 수정 가능
- 수정 이력은 별도 저장하지 않음 (마지막 값만 유지)
- 수정 후 즉시 반영

**데이터 활용 안내 (UI 문구)**

> "입력하신 정보는 작품 추천과 창작자에게 제공되는 통계(연령·성별 등의 분포)에만 활용됩니다. 다른 사용자에게는 공개되지 않습니다."
> 

**화면 구성**

1. 시작 화면: 온보딩 목적 안내 + "시작하기" 버튼
2. 연령대 선택
3. 성별 선택
4. 지역 선택 (스킵 가능)
5. 선호 장르 선택 (다중)
6. 콘텐츠 종류 가중치 (스킵 가능)
7. 완료 화면: 입력 요약 + "탐색 시작하기" 버튼

각 단계 상단에 진행률(예: 3/7) 표시.

**예외 처리**

- 네트워크 오류로 저장 실패: 입력값 로컬 임시 저장 후 재시도 안내
- 중간 이탈: 다음 로그인 시 `onboarding_completed=false`이면 온보딩 자동 진입
- 이미 완료한 사용자 재진입: 설정 화면으로 리다이렉트

---

### F-AC-04 권한 기반 라우팅 (필수)

**처리**

- 모든 화면 진입 시 사용자 권한 확인
- 권한 외 화면 접근 시 차단 + 권한별 메인 화면으로 리다이렉트
- 비로그인 상태로 보호된 화면 접근 시 로그인 화면으로 리다이렉트

| 화면 | 접근 가능 권한 |
| --- | --- |
| 티저 업로드 / 비공개 정보 입력 | 창작자 |
| 컨텐츠 심사 화면 | 관리자 |
| 창작자 대시보드 | 창작자 |
| 미심사/심사 컨텐츠 리스트 | 관리자 |
| 블라인드 탐색 / 하이퍼링크 제공 | 소비자 |
| 외부 안내 발송 | 창작자 |

## 2. 컨텐츠 업로드 (CT)

### F-CT-01 티저 업로드 (필수)

**입력**

- 티저 영상 파일
- 콘텐츠 종류: 영화 / 드라마 / 숏폼 (단일 선택)

**파일 정책**

- 지원 포맷: mp4, mov
- 티저 최대 용량: 100MB

**티저 길이 검증**

- 드라마: 15-30초
- 영화: 15-45초
- 책: 티저 **영상** 15-30초
- 공연(뮤지컬류): 15-45초
- 길이 검증 실패 시 업로드 거부

**처리 로직**

- 파일 업로드 진행률 표시 (0~100%)
- 업로드 중 사용자가 화면을 이탈하면 업로드 취소
- 클라우드 스토리지(예: S3)에 저장
- 업로드 실패 시 자동 재시도 1회 (총 2회까지 시도)
- 성공 시 Content 엔티티에 다음 정보 저장:
    - 티저 URL
    - 콘텐츠 종류, 티저 길이
    - 업로드 시점 타임스탬프
    - 심사 상태 `pending`

**출력**

- 성공 시 → F-CT-02(비공개 정보 입력)으로 이동
- 실패 시 → 사유 메시지 표시 + 재시도 버튼

**워터마크 / 로고 안내 (UI 문구)**
업로드 화면 상단에 명시:

> "베일은 작품을 사전 정보 없이 보여주는 플랫폼입니다. (1) 티저 영상에 로고, 워터마크, 창작자 이름 등 정체를 드러내는 시각 요소가 포함되거나 (2) 자막을 제외한 글자를 활용한 정보 제공 시 심사에서 반려될 수 있습니다."
> 

자동 검출은 MVP에서 제외하며, 관리자 심사 단계에서 수동 확인.

**예외**

- 길이 미달/초과: "티저 영상은 X~Y초여야 합니다 (현재: Z초)"
- 파일 크기 초과: "티저는 최대 100MB까지 업로드 가능합니다"
- 지원 안 되는 포맷: "mp4, mov 형식만 지원됩니다"
- 중복 업로드: "이미 업로드된 영상입니다"
- 네트워크 오류: 진행률 유지 + 자동 재시도 안내

---

### F-CT-02 비공개 정보 입력 (필수)

**입력**

| 항목 | 타입 | 필수 여부 | 제약 |
| --- | --- | --- | --- |
| 제목 | 텍스트 | 필수 | 최대 50자 |
| 시놉시스 | 텍스트 | 필수 | 최대 500자 |
| 장르 태그 | 다중 선택 | 필수, 최소 1개 | 표준 13개 분류 |
| 감독/크리에이터 목록 | 텍스트 (콤마 구분) | 선택 | 최대 10명 |
| 개봉일 | 날짜 | 선택 | YYYY-MM-DD |
| 연령 등급 | 단일 선택 | 필수 | 전체관람가 / 12세 / 15세 / 청소년 관람불가 |
| 외부 링크 | URL | 선택 | MVP에서는 미사용 가능 |

**장르 안내 (UI 문구)**
입력 화면에 명시:

> "장르는 추천 알고리즘과 통계에만 활용되며, 소비자에게는 작품 정보 공개 시점까지 표시되지 않습니다."
> 

**처리**

- 모든 정보를 Content 엔티티의 비공개 정보 필드에 저장
- 저장 후 심사 대기 상태(`pending`) 유지
- 저장 시점 타임스탬프 기록

**출력**

- 성공 시 → 창작자 대시보드로 이동, "심사 대기 중" 상태 표시
- 실패 시 → 사유 메시지 표시

**예외**

- 필수 항목 누락 시 저장 불가
- 글자수 초과: 인라인 오류

---

### F-CT-03 업로드 컨텐츠 목록 조회 (필수)

**입력**: 창작자 ID (세션에서 추출)

**처리**

- 해당 창작자의 모든 컨텐츠 조회
- 심사 상태별 필터 (pending / approved / rejected)
- 정렬: 업로드 일시 내림차순

**출력**

- 컨텐츠 카드 리스트
    - 표시 정보: 제목, 콘텐츠 종류, 심사 상태, 업로드 일시
    - 반려된 경우 반려 사유 함께 표시
    - 승인된 경우 "통계 보기" 버튼 (F-DS-01로 이동)

## 3. 컨텐츠 심사 (RV)

### F-RV-01 미심사 컨텐츠 리스트 (필수)

**입력**: 관리자 권한 확인

**처리**

- `pending` 상태의 모든 컨텐츠 조회
- 정렬: 업로드 일시 오름차순 (오래된 것부터)
- 페이지네이션: 페이지당 10건

**출력**

- 컨텐츠 카드 리스트
    - 표시 정보: 콘텐츠 종류, 업로드 일시, 창작자 ID(또는 마스킹된 이메일), "심사 진입" 버튼
- 미심사 건수 상단 배지 표시
- 검색/필터:
    - 콘텐츠 종류별 필터
    - 업로드 일시 범위 필터

**예외**

- 미심사 건이 없는 경우: "심사 대기 중인 컨텐츠가 없습니다" 빈 상태 표시

---

### F-RV-02 컨텐츠 심사 진행 (필수)

**입력**: 컨텐츠 ID

**관리자 화면 표시**

- 티저 영상 (재생 가능)
- 비공개 정보 전체:
    - 제목, 시놉시스, 장르
    - 감독/크리에이터 목록
    - 개봉일, 연령 등급
    - 외부 링크
- 창작자 정보 (이메일 등)
- 업로드 일시

**심사 체크리스트 (UI 가이드)**
관리자가 검토할 항목을 화면 우측 또는 하단에 체크리스트 형태로 제시:

- [ ]  티저 영상에 워터마크/로고/창작자 식별 요소가 없는가?
- [ ]  티저 길이가 콘텐츠 종류별 규정을 충족하는가? (자동 통과 표시)
- [ ]  부적절한 컨텐츠(폭력·선정성·혐오 등)가 심의에 맞는가?
- [ ]  비공개 정보(제목·시놉시스·장르)가 작품과 일치하는가?

**관리자 액션**

- 승인 버튼
- 반려 버튼 + 체크리스트에 미체크 항목 자동 전송

**처리**

- 승인 시:
    - 심사 상태 `approved`
    - 승인 시점 타임스탬프 기록
    - 컨텐츠 리스트 노출 시작
    - F-NT-03 (창작자 알림) 트리거
- 반려 시:
    - 심사 상태 `rejected`
    - 반려 사유 저장
    - F-NT-03 (창작자 알림) 트리거 (사유 포함)

**예외**

- 이미 처리된 컨텐츠 재진입: "이미 처리된 컨텐츠입니다" 메시지 + 결과 표시

## 4. 소비자 탐색 (EX)

### F-EX-01 콘텐츠 종류 필터 (필수)

**입력**: 영화 / 드라마 /  책 / 공연 (다중 선택 또는 단일 선택)

**제약**

- 최소 1개 이상 선택 필수
- 모두 선택 / 모두 해제 불가
- 기본값: 온보딩에서 입력한 콘텐츠 종류 가중치 (없으면 전체 선택)

**처리**

- 사용자 세션에 필터 상태 저장
- 필터 변경 즉시 다음 탐색 화면에 반영

**출력**

- 필터 설정 후 → 블라인드 탐색 화면(F-EX-02)으로 이동
- 변경 후 즉시 리스트 갱신

**비고**

- 최초 가입 시 1회 안내 화면으로 노출, 이후에는 탐색 화면 상단의 필터 아이콘에서 변경 가능

### F-EX-02 블라인드 티저 피드 (필수)

**개요**
풀스크린 세로 영상 피드 형식. 인스타그램 릴스와 동일한 인터랙션 모델을 따른다. 사용자는 한 번에 하나의 티저 영상을 풀스크린으로 시청하고, 위/아래 스와이프로 영상을 이동하며, 관심 버튼으로 좋아요와 동일한 가벼운 인터랙션을 한다. 베일의 "결정 피로 제거" 가치에 맞춰 카드 비교 단계 없이 바로 영상 감상으로 진입한다.

### 입력

- 사용자 세션 (콘텐츠 종류 필터, 패스 이력, 관심 이력)

### 조회 조건

다음 모든 조건을 만족하는 컨텐츠를 후보군으로 한다.

- 심사 상태 `approved`
- 사용자가 선택한 콘텐츠 종류 필터에 일치
- 사용자가 이미 관심을 누른 컨텐츠는 제외 (별도 "내 관심 목록"에서 조회)

### 노출 알고리즘 (MVP)

**기본 방식**: 무작위 셔플

**제약**

- 같은 창작자의 컨텐츠가 연속 노출되지 않음 (최소 2개 컨텐츠 간격)
- 한 번에 로드되는 묶음 안에 같은 장르가 50% 이상 차지하지 않도록 분산
- 패스한 적 있는 컨텐츠는 노출 가중치 감소 (누적 20% 곱연산 적용)
    - 1회 패스: 0.8
    - 2회 패스: 0.64(0.8*0.8)
    - 이후 동일 곱연산
- 같은 세션 내 패스한 컨텐츠는 최소 5개 컨텐츠 이후에만 재노출

**재노출 차단 기간 없음**

- 패스는 "다음 영상으로 넘긴 가벼운 행위"로 정의되므로 절대 차단 기간을 두지 않음
- 누적 가중치만으로 반복 노출 자연 감소
- 세션 내 최소 간격(5개)만 적용하여 직후 재노출 어색함 방지

**v2 이후**: 다양성 알고리즘 정교화, 취향 기반 가중치, 시청 데이터 기반 정렬

### 피드 로딩

- 무한 스크롤 방식
- 1회 로드 시 5건의 영상을 미리 큐잉
- 큐잉된 영상의 중간(2번째 진입) 시점에 다음 5건 백그라운드 로드
- 사용자가 끊김 없이 다음 영상으로 넘어가도록 영상 미리 버퍼링

### 화면 UI

**기본 구성**

- 영상이 화면 전체를 차지 (풀스크린 세로)
- 영상 위에 다음 요소만 표시:
    - **관심 버튼** (시각적으로 강조, 화면 우측 또는 우하단, 좋아요 하트 아이콘 형태)
    - 닫기(X) 버튼 (화면 상단)
    - 시크바 (영상 재생 위치 표시, 사용자가 직접 이동 가능)
- 그 외 메타정보 일절 표시 금지:
    - 제목, 창작자, 장르, 시놉시스, 평점, 좋아요 수, 조회수, 개봉일 등

**관심 버튼 동작**

- 우측 버튼 클릭으로 관심 처리
- 인스타그램 릴스의 좋아요 인터랙션과 동일한 사용자 경험
- 관심 처리 시 짧은 애니메이션 효과 (하트 채워짐 등)

### 영상 재생

- 영상 진입 시 자동 재생 시작
- 음량 ON 기본값 (사용자가 음소거 가능)
- 일시정지/재개 가능 (영상 영역 단일 탭, 단 더블 탭과 구분 필요)
- 시크바 제공 (구간 이동 가능)
- 영상 길이는 콘텐츠 종류별 차등 (15~90초)

**영상 자연 종료 시**

- 정지해 있음
- 자동으로 다음 영상으로 넘어가지 않음

### 인터랙션

| 동작 | 결과 |
| --- | --- |
| 위로 스와이프 | 패스 처리 (F-EX-04), 다음 영상으로 이동 |
| 아래로 스와이프 | 이전 영상으로 복귀 (패스 기록은 유지) |
| 관심 버튼 탭 | 관심 처리 (F-EX-05), 베일 해제 화면으로 이동 |
| 닫기(X) 버튼 | 피드 종료, 메인 화면으로 복귀 |

**이전 영상 복귀 시 동작**

- 아래 스와이프로 이전 영상으로 돌아갈 수 있음
- 이전 영상에 대한 패스 기록은 유지됨 (이미 위로 넘긴 시점에 패스 처리됨)
- 이전 영상에서 관심 버튼을 다시 누르면 관심 처리 가능 (마음이 바뀐 경우)

**관심 처리 후 흐름**

- 관심 버튼 탭 또는 더블 탭 → 즉시 베일 해제 화면(F-EX-05)으로 이동
- 베일 해제 화면에서 사용자가 닫고 나오면 피드의 다음 영상부터 재개

### 빈 상태 처리

- 노출할 컨텐츠가 없는 경우:
    - "지금 볼 수 있는 작품을 준비 중입니다. 잠시 후 다시 확인해주세요" 안내 화면
- 콘텐츠 종류 필터 때문에 비어있는 경우:
    - 안내 + "필터 변경하기" 버튼 제공

**처리**

    - 또는 다음 티저로 자동 이동 (UX 결정 필요, MVP는 리스트로 복귀로 통일)

**출력**

- 탐색 리스트 화면으로 복귀

### F-EX-05 관심 처리 + 베일 해제 (필수)

**입력**: 컨텐츠 ID, 사용자 ID

**처리**

- Reaction 엔티티에 `type=interest`, 시점 기록
- 동시에 InfoReveal 엔티티 기록 (창작자 알림 트리거용)

**출력 화면 전환**

- 베일 해제 애니메이션 (선택적 UX, MVP에서는 단순 페이드 전환 가능)
- 컨텐츠 상세 화면 표시:

    - 창작자 / 감독 목록
    - 시놉시스
    - 장르
    - 개봉일
    - 연령 등급
    - 외부 링크 (있을 경우)
- 화면 하단 안내:
    
    > "관심 목록에 추가되었습니다. 창작자가 외부 상영·구매 정보를 안내할 수 있습니다."
    > 

**부수 효과**

- F-NT-01 (창작자에게 정보 열람 알림) 트리거

**예외**

- 이미 관심을 누른 컨텐츠 재진입: 베일 해제 화면을 그대로 보여줌 (별도 알림 트리거 없음)

### F-EX-06 내 관심 목록 (필수)

**입력**: 사용자 ID

**처리**

- 해당 사용자가 관심을 누른 모든 컨텐츠 조회
- 외부 안내 수신 여부와 매칭
- 정렬: 관심 누른 시점 내림차순

**출력**

- 컨텐츠 카드 리스트 (정보 공개 상태)
    - 표시 정보: 제목, 창작자, 장르, 관심 누른 일시
    - 외부 안내 도착 시 "안내 도착" 배지 표시
- 빈 상태: "아직 관심 누른 작품이 없습니다. 탐색 화면에서 작품을 발견해보세요"

**부가 액션**

- 카드 탭 시: 컨텐츠 상세 화면 (정보 열람 + 도착한 외부 안내가 있으면 함께 표시)
- 관심 해제 버튼: 관심 목록에서 제거 (Reaction 엔티티 삭제 또는 비활성화)

## 5. 외부 안내 (IV)

### F-IV-01 관심 소비자 리스트 조회 (창작자) (필수)

**입력**: 컨텐츠 ID, 창작자 ID

**처리**

- 해당 컨텐츠에 `type=interest`로 반응한 소비자 목록 조회
- 정렬: 관심 누른 시점 내림차순

**출력**

- 소비자 리스트
    - 표시 정보: 익명화된 인구통계 정보 (연령대, 성별, 지역) - 창작자 통계 활용 목적
- 상태:
    - 미발송: "안내 발송" 버튼 활성화
    - 발송 완료: "안내 발송 완료" 표시 + 발송 일시

**프라이버시 원칙**

- 소비자의 실명, 이메일, 전화번호 등은 창작자에게 일절 노출되지 않음
- 익명 식별자는 시스템 내부에서 컨텐츠별로 일관되게 유지 (다른 컨텐츠에서는 다른 식별자 사용 가능)

---

### F-IV-02 외부 안내 발송 (창작자) (필수)

**목적**

창작자가 관심을 누른 소비자에게 작품을 실제로 만날 수 있는 경로(외부 상영, VOD, 구매 페이지, 굿즈 스토어 등)를 일괄 안내한다. 베일 내부에는 풀버전 영상이 없으므로, 작품과 소비자를 연결하는 채널은 이 외부 링크로 일원화된다.

**입력**

| 항목 | 타입 | 필수 여부 | 제약 |
| --- | --- | --- | --- |
| 컨텐츠 ID | - | 필수 | - |
| 대상 소비자 ID 리스트 | 다중 선택 | 필수, 최소 1명 | F-IV-01에서 선택 |
| 외부 링크 URL | URL | 필수 | http(s) 스킴, 최대 2,000자 |
| 안내 메시지 | 텍스트 | 필수 | 최대 300자 |
| 링크 라벨 | 텍스트 | 선택 | 최대 30자 (예: "예매하기", "스트리밍") |

**발송 단위**

- 일괄 발송 (선택한 모든 소비자에게 동일한 링크와 메시지 전송)

**처리**

- 각 대상 소비자별로 ExternalNotice 엔티티 생성, status=`sent`
- URL 형식 검증 (정규식, http/https 스킴 한정)
- 발송 시점 타임스탬프 기록
- 대상 소비자에게 인앱 알림 발송 (F-NT-02)

**중복 발송 방지**

- 3일 이내 동일 컨텐츠에 대한 재발송 제한, 최대 횟수 2회
- 단, 외부 링크 URL이 변경된 경우는 새 안내로 간주하여 발송 허용

**발송 후 취소 정책**

- MVP에서는 취소 기능 미제공
- 잘못 보낸 경우 관리자 문의 안내 (실무적 운영)

**출력**

- 발송 완료 메시지: "N명에게 안내를 발송했습니다"

**예외**

- 발송 대상 0명: 버튼 비활성화
- URL 형식 오류: 인라인 오류 메시지
- 일괄 발송 중 일부 실패: 실패 건수만 재발송 허용

**비고**

- MVP에서는 일괄 발송만 지원
- 링크 클릭 추적은 v2

---

### F-IV-03 외부 안내 수신 (소비자) (필수)

**입력**: 사용자 ID

**처리**

- 해당 사용자가 받은 ExternalNotice 조회
- 정렬: 발송 시점 내림차순

**출력**

- 알림 영역에 "외부 안내 도착" 표시 (F-NT-02 연동)
- 내 관심 목록(F-EX-06) 내 해당 컨텐츠 카드에 "안내 도착" 배지
- 컨텐츠 상세 화면 진입 시 안내 영역 노출:
    - 표시 정보: 안내 메시지, 외부 링크(라벨 또는 URL), 발송 일시
    - 링크 탭 시: 외부 브라우저로 이동 (사용자에게 외부 이동 사실 안내)

**부가 동작**

- 동일 컨텐츠에 대해 여러 번 안내가 도착한 경우, 가장 최근 안내를 메인으로 표시하고 이전 안내는 접어두기 (선택)

## 6. 창작자 대시보드 (DS)

### F-DS-01 대시보드 메인 (창작자 홈) (필수)

**입력**: 창작자 ID

**처리**

- 해당 창작자의 모든 컨텐츠 요약 정보 조회
- Reaction 엔티티 집계 (관심 수, 노출 수)

**출력 화면 구성**

**1) 상단 요약**

- 총 업로드 컨텐츠 수
- 승인된 컨텐츠 수
- 심사 대기 중 수
- 반려된 수

**2) 알림 영역**

- 미확인 알림 수
- 최근 알림 3개 미리보기 (F-NT 도메인 연동)

**3) 컨텐츠 카드 리스트**

- 각 카드 표시 정보:
    - 제목
    - 콘텐츠 종류
    - 심사 상태
    - 노출 수 (티저가 피드에 노출된 누적 횟수)
    - 관심 수 (해당 컨텐츠에 관심을 누른 누적 사용자 수)
    - "관심 소비자 보기" 버튼 → F-IV-01로 이동
- 정렬: 최근 활동순 또는 업로드 일시순 (사용자 선택)

**4) "+ 새 컨텐츠 업로드" 버튼**

- F-CT-01로 이동

**갱신 주기**

- 노출 수·관심 수: 실시간 (Reaction 집계 기반)
- 사용자가 대시보드 진입 시 최신 데이터 조회

**비고**

- MVP에서는 컨텐츠 카드에 노출 수와 관심 수 두 지표만 표시한다
- 인구통계 분포·완료율·재시청률·시그널 토글 등 상세 지표는 v2 이후 검토
- 별도의 컨텐츠별 상세 통계 화면은 두지 않는다

## 7. 알림 (NT)

### F-NT-01 창작자 정보 열람 알림 (필수)

**트리거**: F-EX-05 (관심 처리)

**처리**

- 해당 컨텐츠의 창작자에게 인앱 알림 생성
- 알림 엔티티(Notification)에 다음 정보 기록:
    - 수신자 (창작자 ID)
    - 알림 종류 (`info_reveal`)
    - 관련 컨텐츠 ID
    - 익명화된 소비자 식별자
    - 발생 시점

**알림 메시지**

> "당신의 작품 [제목]에 새로운 관심이 도착했습니다"
> 

**출력**

- 창작자 알림 영역에 표시
- 미확인 알림 수 배지 갱신
- 알림 탭 시 → F-IV-01 (관심 소비자 리스트)로 이동

**중복 방지**

- 같은 (소비자, 컨텐츠) 조합에서 이미 InfoReveal 이벤트가 있는 경우 알림 재생성하지 않음
- 단, 정보 열람 카운트는 기록

**비고**

- MVP에서는 인앱 알림만 지원
- 푸시 알림(이메일, 모바일 푸시)은 v2

---

### F-NT-02 외부 안내 알림 (필수)

**트리거**: F-IV-02 (외부 안내 발송)

**처리**

- 해당 소비자에게 인앱 알림 생성
- 알림 엔티티에 다음 정보 기록:
    - 수신자 (소비자 ID)
    - 알림 종류 (`external_notice`)
    - 관련 컨텐츠 ID
    - 발생 시점

**알림 메시지**

> "관심 누른 작품의 새 안내가 도착했습니다"
> 

**출력**

- 소비자 알림 영역에 표시
- 내 관심 목록(F-EX-06)의 해당 컨텐츠 카드에 "안내 도착" 배지 동시 갱신
- 알림 탭 시 → 컨텐츠 상세 화면으로 이동 (안내 메시지·외부 링크 함께 표시)

**비고**

- 같은 컨텐츠에 대한 중복 안내는 F-IV-02에서 차단되므로 알림도 동일하게 제한됨

---

### F-NT-03 컨텐츠 심사 결과 알림 (필수)

**트리거**: F-RV-02 (승인 또는 반려)

**처리**

- 해당 창작자에게 인앱 알림 생성
- 알림 엔티티에 다음 정보 기록:
    - 수신자 (창작자 ID)
    - 알림 종류 (`review_result`)
    - 관련 컨텐츠 ID
    - 결과 (`approved` / `rejected`)
    - 반려 사유 (반려 시)
    - 발생 시점

**알림 메시지**

- 승인: "[제목]이 승인되어 배포되었습니다"
- 반려: "[제목]이 반려되었습니다"
    - 알림 상세 진입 시 반려 사유 전문 표시

**출력**

- 창작자 알림 영역에 표시
- 알림 탭 시 → 해당 컨텐츠 상세 화면 또는 업로드 컨텐츠 목록(F-CT-03)으로 이동

---

### F-NT-04 알림 목록 화면 (필수)

**입력**: 사용자 ID

**처리**

- 해당 사용자의 모든 Notification 엔티티 조회
- 정렬: 발생 시점 내림차순
- 페이지네이션: 페이지당 20건

**출력**

- 알림 카드 리스트
    - 표시 정보: 알림 메시지, 발생 시점, 읽음 상태
    - 미확인 알림은 배경 강조 또는 점 표시

**부가 동작**

- 카드 탭 시:
    - 알림 종류에 따라 적절한 화면으로 이동 (F-NT-01~03 참조)
    - 읽음 처리(`is_read=true`)
- "모두 읽음 처리" 버튼: 모든 알림 일괄 읽음 처리

**빈 상태**

- "새로운 알림이 없습니다"

---

### F-NT-05 알림 미확인 수 표시 (필수)

**처리**

- 사용자의 미확인 알림(`is_read=false`) 수 집계
- 메인 네비게이션의 알림 아이콘에 배지로 표시

**갱신 시점**

- 새 알림 생성 시 즉시
- 알림 읽음 처리 시 즉시

**표시 규칙**

- 1~9: 숫자 그대로 (예: "3")
- 10 이상: "9+"
- 0: 배지 표시 안 함

---

### F-NT-06 알림 데이터 모델 (참고)

```
related_content_id
related_user_id (nullable, 익명화된 소비자 식별자)
extra_data (jsonb, 반려 사유 등 추가 정보)
is_read (boolean)

```

## 9. 시연 시나리오 (참고)

MVP 검증을 위한 권장 시연 흐름:

**사전 준비**

- 창작자 계정 1개 생성
- 컨텐츠 2개 사전 업로드 + 관리자 승인 완료
- 소비자 계정 1개 (온보딩 완료)

**시연 단계**

1. **창작자 측**: 새 컨텐츠 업로드 → 비공개 정보 입력 → 심사 대기
2. **관리자 측**: 미심사 리스트 진입 → 심사 → 승인
3. **소비자 측**:
    - 로그인 → 블라인드 탐색 화면 진입
    - 3개의 티저 카드 노출 (사전 2개 + 방금 승인된 1개)
    - 청중에게 "가장 보고 싶은 것" 선택 받음
    - 1개에 "관심" 누름 → 베일 해제 화면 표시
4. **창작자 측 (실시간)**: 정보 열람 알림 수신 확인
5. **창작자 측**: 관심 소비자 리스트 진입 → 외부 안내 발송 (외부 상영·구매 링크 + 안내 메시지)
6. **소비자 측**: 외부 안내 알림 수신 → 컨텐츠 상세에서 안내 메시지·외부 링크 확인
7. **창작자 측**: 대시보드에서 해당 컨텐츠의 노출 수·관심 수 확인

이 시연으로 베일의 핵심 가치(블라인드 큐레이션, 정보 통제권, 창작자-소비자 연결)가 전달된다.
